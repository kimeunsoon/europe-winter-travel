# 유럽겨울여행

50~60대 여성을 위한 1·2월/8월 유럽 여행 동아리 웹앱입니다. Next.js App Router, TypeScript, Supabase를 사용합니다.

## 실행

Node.js 22 이상에서 `npm install`, `npm run dev`, `npm run build`를 실행합니다.

## 기능

- 계절/도시/여행 스타일 필터, 상세 일정, 브라우저에 저장되는 찜 목록
- 라이트/다크 모드, 모바일/태블릿/데스크톱 반응형
- 동아리 가입, 게시판 작성/공감, 3문항 여행 퀴즈와 랭킹
- DB 미설정 시 명시적인 체험 모드 (가입·글은 브라우저 저장)
- 모든 여행 일정, 모집 인원, 예산 및 초기 이야기는 시연 데이터입니다. 예약/결제 서비스가 아닙니다.

## Supabase

Vercel Storage에서 Supabase를 연결할 때 Seoul (`ap-northeast-2`)을 선택합니다. `.env.example`의 공개 URL/키를 환경변수에 등록합니다. Supabase SQL Editor에서 `supabase/migrations/001_initial.sql`을 실행하고 Authentication > Sign In / Providers에서 Anonymous Sign-ins를 활성화해야 가입 기능이 동작합니다. 익명 사용자는 인증된 UUID로 식별하며 회원 정보는 본인만 읽고 수정할 수 있습니다. 공개 게시물/랭킹은 읽기가 가능하고 회원만 자신의 이름으로 작성할 수 있습니다. 공감은 회원별 1회입니다. 퀴즈 점수는 보상이 없는 자기 기록용 클라이언트 점수이며 부정행위 방지용이 아닙니다. 브라우저 저장소를 지우면 익명 계정 접근은 복구되지 않습니다.

`vercel.json`에 서버 리전 `icn1`이 지정되어 있습니다. 실제 서버 리전은 배포된 `/api/health`에서 확인할 수 있습니다. DB 리전은 Supabase 프로젝트 설정에서 별도 확인해야 합니다. 리전 일치만으로 5ms 이하 RTT를 보장하지 않습니다.

비밀키, 서비스 역할 키, DB 연결 비밀번호는 저장소에 커밋하지 않습니다. 공개 웹에 실제 서비스를 운영할 때는 관리자 운영, 신고/삭제 및 가입 방식 정책을 추가로 정해야 합니다.
